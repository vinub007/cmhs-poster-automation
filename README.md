# cmhs-poster-automation
CMHS Daily Admissions Poster Automation

Automated poster generation system for Columbus Model High School, Miyapur.

This project uses GitHub Actions and Python to automatically create daily “Admissions Open” posters for WhatsApp and Instagram using random school photos, CMHS branding, and dynamic layouts.

**Features:**

Daily automated poster generation at 7 AM IST
Random photo selection from uploaded school images
WhatsApp & Instagram optimized poster sizes
CMHS logo and branding integration
GitHub Actions cloud automation
No Google Cloud or API setup required
Easy weekly photo uploads
Ready for future AI caption and social media automation

**Tech Stack:**

Python
Pillow (PIL)
GitHub Actions

**Ideal for:**

School admissions campaigns
Daily social media marketing
Event promotions
Educational branding automation
